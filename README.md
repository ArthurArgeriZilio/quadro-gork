# Quadro

Quadro digital local em pixel art. A interface é HTML e JavaScript puro, e o servidor usa só a biblioteca padrão do Python 3. Roda apenas em `127.0.0.1:8765`, sem instalar nada.

## Como usar

1. Instale o Python 3.
2. Baixe este repositório.
3. No Windows, dê dois cliques em `iniciar.bat`. No Linux ou no Mac, rode `python servidor.py`.
4. Abra http://127.0.0.1:8765

Os dados ficam no arquivo local `quadro.json`, que não vai para o git.

O guia completo está no [LEIAME.md](LEIAME.md).
